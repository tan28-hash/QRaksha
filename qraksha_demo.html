    Under the hood

    Four checks run on every scan

    The demo above runs simplified versions of these checks entirely client-side. In production, domain and redirect checks call live threat-intel APIs.

    01 · DECODE
    Read the payload
    URL, UPI string, or WiFi config is extracted before anything is opened or connected to.
    02 · INSPECT
    Domain & redirect check
    Typosquat distance against known brands, shortened-link detection, urgency-keyword scan.
    03 · CROSS-CHECK
    UPI & WiFi rules
    Payee VPA pattern checks, open-network warnings for WiFi QRs.
    04 · EXPLAIN
    Plain-language verdict
    Safe / Caution / Danger with the exact reason — no jargon required to act on it.
